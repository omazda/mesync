# Регистрация на платформе

**Кто может подключиться к платформе MAX для партнёров?**
> Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам, Цифровому ID — доступно для юрлиц и ИП, которые являются резидентами РФ

Самозанятые, физические лица и нерезиденты пока не смогут пройти верификацию на платформе

**Какой номер телефона указать при регистрации на платформе для партнёров?**

Регистрируйтесь с рабочим номером телефона ответственного представителя

Номер должен быть актуальным и находиться у вас в постоянном доступе, так как на него будут приходить коды подтверждения и важные уведомления

> Указанному при регистрации номеру телефона будет соответствовать один профиль организации и привязанные к нему сервисы: чат-боты, мини-приложения, каналы, сервисы партнёров и Цифровой ID.  
> Если у вас есть канал с меткой A+ на другой платформе: ВКонтакте, Дзен, Одноклассники, Telegram — вы можете создать в MAX канал с таким же названием и ником. В этом случае при регистрации используйте номер телефона, на который создан канал на другой платформе

**Какие данные указывать при регистрации аккаунта в мессенджере MAX?**

При регистрации в поле для имени и фамилии указывайте имя и фамилию ответственного представителя, а не название организации. Иначе данные такого аккаунта могут быть распознаны как подозрительные — это повлечёт за собой блокировку
