# О платформе

> Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам, Цифровому ID — доступно для юрлиц и ИП, которые являются резидентами РФ

[Платформа MAX для партнёров](https://business.max.ru/self) позволяет выстраивать удобную коммуникацию с клиентами в мессенджере MAX

С помощью платформы вы можете создать [чат-боты](#%D0%9E%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%B0%D1%85) для настройки сценариев диалогов, подключить [мини-приложения](#%D0%9E%20%D0%BC%D0%B8%D0%BD%D0%B8-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%D1%85) для обработки запросов и принятия заказов без перехода на внешние платформы, [добавить канал](#%D0%9E%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D0%B0%D1%85) своей организации в MAX для публикации новостей, а также подключить [сервисы партнёров](#%D0%9E%D0%B1%20%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8%20%D1%81%20%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%B0%D0%BC%D0%B8%20%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%B2) или заказать у них разработку и [создать Цифровой ID](#%D0%9E%20%D0%A6%D0%B8%D1%84%D1%80%D0%BE%D0%B2%D0%BE%D0%BC%20ID)

Платформа MAX для партнёров пока доступна только в веб-версиях:

- **Для компьютера** — работать лучше на экранах от 1440 px, ограничений на браузеры нет
- **Для мобильных устройств с iOS и Android** — поддерживаются экраны от 375 px

[Подключиться к платформе MAX для партнёров](docs/maxbusiness/connection.md)

## О чат-ботах

**Чат-боты экономят время**

С помощью чат-ботов вы можете автоматизировать работу с клиентами, вести бизнес, обучать, продавать и развлекать

Бот создаётся после [подключения](docs/maxbusiness/connection.md) к платформе MAX для партнёров, добавления там организации и её верификации. Бот проходит [модерацию](docs/chatbots/bots-create.md#%D0%AD%D1%82%D0%B0%D0%BF%202.%20%D0%9C%D0%BE%D0%B4%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F) и после этого становится доступен пользователям через MAX

**Для быстрого старта**

Если у вас нет навыков программирования или нужен быстрый старт, используйте [конструкторы](docs/chatbots/bots-nocode/create.md#%D0%9A%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%20%D1%81%D1%86%D0%B5%D0%BD%D0%B0%D1%80%D0%B8%D0%B5%D0%B2%20%D0%B1%D0%BE%D1%82%D0%B0) сервисов партнёров, которые помогут собрать сценарии для бота без кода, по готовым шаблонам

**Для получения всех возможностей чат-бота**

С навыками разработки вы можете [настраивать чат-боты](docs/chatbots/bots-coding/prepare.md), используя все возможности API ботов

[Создать чат-бот на платформе](docs/chatbots/bots-create.md)
  

[Настроить бота без разработки](docs/chatbots/bots-nocode/create.md)[Настроить бота с разработкой](docs/chatbots/bots-coding/prepare.md)

## Об интеграции с сервисами партнёров

После добавления и модерации бота на платформе вы можете подключить сервисы партнёров:

- CRM-системы — для автоматизации рутинных операций и работы с клиентской базой: лидами, заявками, историей общения с клиентами
- Конструкторы мини-приложений — для создания мини-приложений без разработки
- Платформы чат-ботов — для создания сценариев чат-ботов без разработки
- Чат-платформы — для общения с клиентами через сервис партнёров
- Заказная разработка — если хотите поручить создание чат-ботов и мини-приложений в МАХ сервису партнёра под ключ

Для подключения к сервисам партнёров используйте токен бота

Если вы хотите стать официальным партнёром, необходимо [заполнить заявку через платформу](docs/partners-integration.md#%D0%9A%D0%B0%D0%BA%20%D1%81%D1%82%D0%B0%D1%82%D1%8C%20%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%BC)

[Подключить сервисы партнёров или стать партнёром](docs/partners-integration.md)

## О мини-приложениях

**Мини-приложения**

Мини-приложения — это веб-сайты и программы, которые можно запустить прямо в MAX: например, интернет-магазины или игры

![](https://dev.max.ru/assets/about/miniapps_light.png)

Мини-приложения снижают нагрузку на команды продаж и поддержки за счёт возможности принятия заказов без перехода на внешние ресурсы

**Чтобы создать мини-приложение, нужны навыки программирования**

Мини-приложения доступны на разных устройствах и проще в разработке, чем мобильные приложения.
Они работают на стандартных веб-технологиях — HTML, JavaScript, CSS, а ещё их не нужно дорабатывать под разные платформы и модерировать в сторах

**Мини-приложения не могут существовать изолированно**

Для возможности взаимодействовия мини-приложений с API подключите библиотеку MAX Bridge.
Это посредник на стороне пользователя, с помощью которого приложение обменивается данными с клиентской частью MAX.
Библиотека нужна для отправки и получения событий. Подробнее читайте [в разделе «MAX Bridge»](docs/webapps/bridge.md)

Чтобы пользователи не замечали переходы из чатов в мини-приложения, рекомендуем адаптировать интерфейсы сервисов под дизайн-систему MAX.
Создавайте консистентный и привлекательный визуал [с библиотекой React-компонентов MAX UI](ui.md)

**Мини-приложения в MAX должны соответствовать правилам**

Перед размещением мини-приложения в MAX изучите [Правила платформы](docs/legal/rules.md).
Ваш сервис должен соответствовать законам Российской Федерации, а также требованиям к его содержанию и функциональности

[Подключить мини-приложение](docs/webapps/introduction.md)

## О каналах

**В МАХ доступны публичные и приватные каналы**

С помощью публичных каналов вы можете взаимодействовать со своей аудиторией через мессенджер MAX, например публиковать новости и анонсировать акции

Приватные каналы удобно использовать для коммуникаций на ограниченную аудиторию, например, оповещений и публикации новостей только для сотрудников организации.
Количество приватных каналов неограниченно — можно создать несколько, например, для разных отделов или филиалов

Также вы можете использовать приватные каналы для монетизации.
Например, публиковать уникальный контент и выдавать к нему доступ только после оплаты или размещать рекламные посты за деньги

| Критерий | Публичные каналы | Приватные каналы |
| --- | --- | --- |
| **Кто может создать** | Юрлицо или ИП. Физическим лицам недоступно | Любой пользователь мессенджера МАХ с российским номером телефона, в том числе физические лица |
| **Доступность в поиске** | Можно найти по нику, ссылке, названию и описанию | Только по ссылке-приглашению |
| **Никнейм** | Для А+ совпадает с ресурсом на другой платформе и меняется вручную после создания. Для остальных — генерируется автоматически в формате `idИНН_biz` | Нет — только длинная ссылка-приглашение |
| **Подключение к платформе MAX для партнёров** | Не требуется при наличии метки А+. Требуется для остальных | Не требуется |
| **Кто может подписаться** | Все пользователи мессенджера MAX | Пользователи мессенджера MAX, у которых есть ссылка-приглашение |
| **Модерация новых подписчиков** | Нет | Опционально — [заявки на вступление](docs/channels/manage.md#%D0%9A%D0%B0%D0%BA%20%D0%B2%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20%D0%B8%D0%BB%D0%B8%20%D0%BE%D1%82%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20%D0%B7%D0%B0%D1%8F%D0%B2%D0%BA%D0%B8%20%D0%BD%D0%B0%20%D0%B2%D1%81%D1%82%D1%83%D0%BF%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B2%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%C2%A0%E2%80%94%20%D1%82%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D1%80%D0%B8%D0%B2%D0%B0%D1%82%D0%BD%D1%8B%D1%85%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D0%BE%D0%B2) |

Метка А+ присваивается ресурсам на платформах ВКонтакте, Одноклассники, Дзен и Telegram. Чтобы проверить, есть ли у вашего сообщества или канала метка А+, откройте бота [**Каналы в МАХ**](https://max.ru/channel_bot) — он автоматически покажет доступные ресурсы с меткой

**Если у вас уже есть ресурсы с меткой А+ на других платформах, вы можете создать публичные каналы с такими же никами и названиями в MAX**

Для этого воспользуйтесь ботом [**Каналы в МАХ**](https://max.ru/channel_bot).
Можно добавить столько каналов, сколько у вас есть ресурсов с меткой А+ на платформах ВКонтакте, Дзен, Одноклассники или в Telegram

Обратите внимание, что создавать канал в MAX нужно с того же номера, с которого вы подавали заявку на получение метки А+ для стороннего ресурса

[Создать канал с названием и ником, как у ресурса с меткой А+ на другой платформе](docs/channels/create.md#Как%20создать%20канал%20с%20таким%20же%20названием,%20как%20у%20ресурса%20с%C2%A0меткой%C2%A0А+)

**Также вы можете создать публичный канал с выбранным вами названием и автогенерируемым ником**

Создать такой канал можно независимо от наличия ресурсов с меткой А+ и регистрации в Роскомнадзоре. Пока доступно создание только одного такого канала. Вам потребуется [войти на платформу или зарегистрироваться](docs/maxbusiness/connection.md#%D0%AD%D1%82%D0%B0%D0%BF%201.%20%D0%92%D1%85%D0%BE%D0%B4%20%D0%B8%20%D1%80%D0%B5%D0%B3%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%86%D0%B8%D1%8F%20%D0%BD%D0%B0%20%D0%BF%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D0%B5), [создать и верифицировать](docs/maxbusiness/connection.md#%D0%AD%D1%82%D0%B0%D0%BF%202.%20%D0%A1%D0%BE%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%BF%D1%80%D0%BE%D1%84%D0%B8%D0%BB%D1%8F%20%D0%BE%D1%80%D0%B3%D0%B0%D0%BD%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B8%20%D0%B8%D0%BB%D0%B8%20%D0%98%D0%9F)
организацию

После этого вы сможете добавить канал через бота [**Каналы в MAX для бизнеса**](https://max.ru/business_channel_bot).
Название канала вы выбираете сами, а ник генерируется автоматически.
Обратите внимание, что профиль в MAX должен быть создан на тот же номер телефона, что вы использовали при регистрации на платформе

Для безопасности мы разделили добавление и повседневное использование канала между двумя платформами:

- В MAX для партнёров вы верифицируете организацию и инициируете создание канала
- В мессенджере MAX вы непосредственно создаёте канал, управляете его настройками и публикуете посты

[Создать канал с выбранным вами названием и автогенерируемым ником](docs/channels/create.md#Как%20создать%20канал%20с%20выбранным%20вами%20названием)

**Приватный канал можно создать прямо в мессенджере МАХ**

Для [создания приватного канала](docs/channels/create.md#%D0%9F%D1%80%D0%B8%D0%B2%D0%B0%D1%82%D0%BD%D1%8B%D0%B5%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D1%8B) подключаться к платформе МАХ для партнёров не нужно — достаточно быть пользователем мессенджера МАХ с аккаунтом, зарегистрированным на российский номер телефона.
Рекомендуем использовать телефон организации или ответственного, кто будет управлять каналом и [модерировать заявки](docs/channels/manage.md#%D0%9A%D0%B0%D0%BA%20%D0%B2%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20%D0%B8%D0%BB%D0%B8%20%D0%BE%D1%82%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20%D0%B7%D0%B0%D1%8F%D0%B2%D0%BA%D0%B8%20%D0%BD%D0%B0%20%D0%B2%D1%81%D1%82%D1%83%D0%BF%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B2%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%20%E2%80%94%20%D1%82%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D1%80%D0%B8%D0%B2%D0%B0%D1%82%D0%BD%D1%8B%D1%85%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D0%BE%D0%B2) на вступление

Для дополнительной безопасности вы можете [включить](docs/channels/manage.md#%D0%9A%D0%B0%D0%BA%20%D0%B2%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20%D0%B8%D0%BB%D0%B8%20%D0%BE%D1%82%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C%20%D0%B7%D0%B0%D1%8F%D0%B2%D0%BA%D0%B8%20%D0%BD%D0%B0%20%D0%B2%D1%81%D1%82%D1%83%D0%BF%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B2%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%C2%A0%E2%80%94%20%D1%82%D0%BE%D0%BB%D1%8C%D0%BA%D0%BE%20%D0%B4%D0%BB%D1%8F%20%D0%BF%D1%80%D0%B8%D0%B2%D0%B0%D1%82%D0%BD%D1%8B%D1%85%20%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D0%BE%D0%B2) в приватных каналах опцию **Заявка на вступление**: по умолчанию она отключена.
В этом случае пользователи смогут подписаться на канал только после согласования заявки администратором

## О Цифровом ID

Если у вашего магазина или торговой точки подключён Цифровой ID в MAX, покупатели смогут подтвердить совершеннолетие, а также льготные статусы студента, человека с инвалидностью, многодетного и пенсионера без бумажных документов: с помощью QR-кода (Android и iOS) или NFC (только Android) в мессенджере MAX

**Для удобства пользователей подключите Цифровой ID и настройте работу с кассами**

Вы можете добавить Цифровой ID на платформе сразу после [создания и верификации организации](docs/maxbusiness/connection.md#%D0%AD%D0%AD%D1%82%D0%B0%D0%BF%202.%20%D0%A1%D0%BE%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%BF%D1%80%D0%BE%D1%84%D0%B8%D0%BB%D1%8F%20%D0%BE%D1%80%D0%B3%D0%B0%D0%BD%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B8%20%D0%B8%D0%BB%D0%B8%20%D0%98%D0%9F).
Также вам понадобится профиль в мессенджере MAX, зарегистрированный на номер телефона, с которым вы входите на платформу

После подключения на платформе у вас появится токен Цифрового ID. Он нужен для настройки обмена данными между MAX и вашими торговыми точками

**У покупателей также должен быть создан Цифровой ID в мессенджере MAX**

Цифровой ID в мессенджере МАХ — это цифровой аналог бумажных документов, с помощью которого пользователи мессенджера могут подтвердить своё совершеннолетие, а также льготные статусы

Это возможно, потому что пользователи MAX добавляют в Цифровой ID свои документы с Госуслуг и данные проверяются обеими системами.
В будущем возможности Цифрового ID будут расширяться

После создания Цифрового ID в мессенджере MAX у пользователей появляется QR-код, который можно предъявить на кассе вместо паспорта и других бумажных документов для подтверждения совершеннолетия и льготных статусов. Вместо QR-кода покупатели могут также использовать NFC – доступно только для устройств на Android

Покупатели могут предъявить Цифровой ID с помощью QR-кода или NFC кассиру или через кассу самообслуживания. Идентификатор динамический и обновляется каждые 25 секунд

Подробнее о том, как выглядит создание Цифрового ID для покупателей, читайте [в помощи мессенджера MAX](https://help.max.ru/help/account/kak-sozdat-cifrovoj-id-v-max)
