# Подготовка и настройка бота

> Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам, Цифровому ID — доступно для юрлиц и ИП, которые являются резидентами РФ

> Уровень сложности: для начинающих

Чат-боты умеют решать типовые задачи.
Настройте бота, который будет делать что-то за вас, — например, присылать задачи на день или показывать расписание на неделю

Вы можете [создать бота](../bots-create.md), только если у вас есть [верифицированный профиль организации](../../maxbusiness/connection.md#%D0%92%D0%B5%D1%80%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D1%8F) на платформе MAX для партнёров

> Для одной организации доступно создание 5 ботов

Пользователи могут получить доступ к боту после его успешной модерации. [Статус модерации](../bots-create.md#%D0%A1%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B%20%D0%BC%D0%BE%D0%B4%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8) отображается рядом с названием бота

Даже без навыков программирования подготовить своего бота в приложении просто — придумайте сценарий с использованием конструктора и следуйте [инструкции ниже](create.md#%D0%9A%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%20%D1%81%D1%86%D0%B5%D0%BD%D0%B0%D1%80%D0%B8%D0%B5%D0%B2%20%D0%B1%D0%BE%D1%82%D0%B0)

Если у вас есть навыки разработки и вы хотите подключить к чат-боту мини-приложение в MAX, читайте [раздел «Бот с разработкой: подготовка и настройка»](../bots-coding/prepare.md)

## Настройки бота

У бота в MAX есть следующие поля и настройки:

- Имя, которое отображается в MAX в чате с вашим ботом, — задаётся при создании бота в поле **Название**
- Аватар (фото профиля) — загружается в виде логотипа при создании бота
- Ник, который отображается в публичной ссылке, например для `https://max.ru/idИНН_bot` ником является `idИНН_bot`. Он генерируется автоматически при создании бота по шаблону `idИНН_bot`
- Описание для пользователя, где указано, какие задачи решает бот: что умеет, чем полезен, как связаться с его владельцем или поддержкой. Всё это указывается при создании бота в поле **Описание**

Настройки бота можно изменить только на платформе MAX для партнёров — отредактировать их в мессенджере MAX не получится

Вы можете [изменить](manage.md#%D0%9A%D0%B0%D0%BA%20%D0%B8%D0%B7%D0%BC%D0%B5%D0%BD%D0%B8%D1%82%D1%8C%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8%20%D0%B1%D0%BE%D1%82%D0%B0) имя, аватар и описание.
Отредактировать ник пока нельзя. При изменении настроек обратите внимание на [требования к полям](../bots-create.md#%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8%20%D0%B1%D0%BE%D1%82%D0%B0)

Также в настройках бота на платформе вы можете [запретить или разрешить](manage.md#%D0%9A%D0%B0%D0%BA%20%D1%80%D0%B0%D0%B7%D1%80%D0%B5%D1%88%D0%B8%D1%82%D1%8C%20%D0%B8%D0%BB%D0%B8%20%D0%B7%D0%B0%D0%BF%D1%80%D0%B5%D1%82%D0%B8%D1%82%D1%8C%20%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B1%D0%BE%D1%82%D0%B0%20%D0%B2%20%D0%B3%D1%80%D1%83%D0%BF%D0%BF%D0%BE%D0%B2%D0%BE%D0%B9%20%D1%87%D0%B0%D1%82) добавление бота в групповой чат.

## Токен бота

После успешной проверки чат-бота в разделе **Чат-боты** → **Перейти** → **Расширенные настройки** → **Настроить** появится токен — уникальный идентификатор бота, с помощью которого он будет взаимодействовать с [API MAX](../../../docs-api.md)

![](https://dev.max.ru/assets/chat_bots/bots_and_miniapps_settings_on_main.png)

![](https://dev.max.ru/assets/chat_bots/bots_and_miniapps_to_settings.png)

![](https://dev.max.ru/assets/chat_bots/integration_token.png)

*Получение токена бота*

Наличие токена означает, что бот зарегистрирован на платформе MAX для партнёров

> **Пример токена**  
>   
> `AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`

**Токен** — это прямой доступ к боту. Не рекомендуем хранить его в открытых источниках или передавать посторонним — они смогут завладеть ботом и управлять им от вашего имени.
Если вы опасаетесь, что токен скомпрометирован, [обновите его](manage.md#%D0%9A%D0%B0%D0%BA%20%D0%BE%D0%B1%D0%BD%D0%BE%D0%B2%D0%B8%D1%82%D1%8C%20%D1%82%D0%BE%D0%BA%D0%B5%D0%BD%20%D0%B1%D0%BE%D1%82%D0%B0)

После того, как бот настроен, остаётся самое интересное — надо продумать логику ответов бота и написать фразы, которыми он будет «разговаривать» в чате. Вам понадобится конструктор

## Конструктор сценариев бота

Конструкторы ботов предоставляют готовые шаблоны для создания сценариев ботов, а также инструменты для управления и аналитики. Это позволяет быстро запустить чат-боты без разработки и программирования.
Кроме того, конструкторы поддерживают интеграцию с AI-решениями, что позволяет автоматизировать рутинные задачи, например обзвон клиентов и приём заказов

Мы рекомендуем работать на платформах [официальных партнёров MAX](../../partners-integration.md#%D0%9F%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BA%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%D1%8B%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%BE%D0%B2).
Вы можете выборочно подключить встроенные сервисы для работы с клиентами, маркетингом и платёжными системами или полностью делегировать свои проекты

**Как работать с конструктором**

1. Выберите любой конструктор из списка [официальных партнёров MAX](../../partners-integration.md#%D0%9F%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BA%D0%BE%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%82%D0%BE%D1%80%D1%8B%20%D1%87%D0%B0%D1%82-%D0%B1%D0%BE%D1%82%D0%BE%D0%B2), перейдите на сайт партнёра и зарегистрируйтесь. Рекомендуем работать на компьютере — в мобильной версии некоторые функции конструкторов могут быть недоступны  
2. У разных конструкторов последовательность действий при настройке бота может отличаться, следуйте подсказкам на сайте сервиса.
Заполните блоки и кнопки, настройте сбор данных, чтобы проанализировать эффективность вашего сценария после запуска бота

**Добавление мини-приложения в MAX через конструктор**

К боту с настроенным сценарием можно [подключить мини-приложение](../../webapps/introduction.md).
Для этого в настройках конструктора найдите MAX, укажите в нужном поле токен бота и активируйте интеграцию кнопкой или переключателем. Готово! Перейдите в мини-приложение
