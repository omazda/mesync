# Подключение к Цифровому ID

> Подключение к платформе MAX для партнёров и её сервисам — чат-ботам, мини-приложениям, каналам, Цифровому ID — доступно для юрлиц и ИП, которые являются резидентами РФ

Если у вашего магазина или торговой точки подключён Цифровой ID в MAX, покупатели смогут подтвердить совершеннолетие, а также льготные статусы студента, человека с инвалидностью, многодетного и пенсионера без бумажных документов: с помощью QR-кода (Android и iOS) или NFC (только Android) в мессенджере MAX

Для этого у покупателей также должен быть создан Цифровой ID в мессенджере MAX

## Цифровой ID для покупателей

Цифровой ID в мессенджере МАХ — это цифровой аналог паспорта и других бумажных документов, с помощью которого пользователи мессенджера могут подтвердить своё совершеннолетие, а также льготные статусы: студент, многодетный, человек с инвалидностью, пенсионер

Это возможно, потому что пользователи MAX добавляют в Цифровой ID свои документы с Госуслуг и данные проверяются обеими системами.
В будущем возможности Цифрового ID будут расширяться

После создания Цифрового ID в мессенджере MAX у пользователей появляется QR-код, который можно предъявить на кассе вместо паспорта и других бумажных документов для подтверждения совершеннолетия и льготных статусов. Вместо QR-кода покупатели могут также использовать NFC – доступно только для устройств на Android

Покупатели могут предъявить Цифровой ID с помощью QR-кода или NFC кассиру или через кассу самообслуживания. Идентификатор динамический и обновляется каждые 25 секунд

Подробнее о создании Цифрового ID для покупателей — [в помощи мессенджера MAX](https://help.max.ru/help/account/kak-sozdat-cifrovoj-id-v-max)

## Цифровой ID для продавцов

Чтобы покупатели могли воспользоваться Цифровым ID в вашем магазине или торговой точке, вам необходимо подключить его через API

Для этого предварительно нужно [зарегистрироваться](maxbusiness/connection.md#%D0%AD%D1%82%D0%B0%D0%BF%202.%20%D0%A1%D0%BE%D0%B7%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%BF%D1%80%D0%BE%D1%84%D0%B8%D0%BB%D1%8F%20%D0%BE%D1%80%D0%B3%D0%B0%D0%BD%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B8%20%D0%B8%D0%BB%D0%B8%20%D0%98%D0%9F) на платформе MAX для партнёров, создать и верифицировать организацию. А затем — получить токен доступа к API Цифрового ID MAX и с его помощью настроить обмен данными между MAX и кассами ваших магазинов или торговых точек

Также перед подключением проверьте, что у вас есть профиль в мессенджере MAX, зарегистрированный на номер телефона, с которым вы входите на платформу

### Как подключить

1. Перейдите в профиль вашей организации на [платформе](https://business.max.ru/self)
2. В разделе **Цифровой ID** выберите **Создать**
3. Нажмите **Получить токен**
4. Дождитесь генерации токена и скопируйте его
5. Нажмите **Инструкция для подключения** — вы перейдёте к описанию API Цифрового ID MAX и сможете настроить взаимодействие с кассами ваших магазинов или торговых точек. Используйте полученный токен для аутентификации при отправке запросов через API Цифрового ID MAX

### Как обновить токен

> - Срок жизни токена Цифрового ID — 1 год
> - Обратите внимание: после обновления токена все магазины и торговые точки, подключённые к Цифровому ID, будут отключены  — вам потребуется настроить взаимодействие по API заново, с новым токеном
> - Если вы хотите обновить токен до окончания его срока жизни, рекомендуем это делать только в **исключительных** случаях, например, если вы подозреваете, что токен попал в руки мошенников

1. Перейдите в профиль организации на [платформе MAX для партнёров](https://business.max.ru/self)
2. В разделе **Цифровой ID** нажмите **Настроить**
3. В правом верхнем углу нажмите на три точки → **Обновить токен**
4. Отправьте заявку на почту с экрана
5. Дождитесь уведомления о смене токена, затем на платформе в разделе **Цифровой ID** нажмите **Настроить** и скопируйте новый токен
6. Перейдите к описанию интеграции по API Цифрового ID MAX, нажав **Инструкция для подключения**, и повторно настройте взаимодействие с вашими магазинами и торговыми точками
