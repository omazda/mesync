# Возврат платежа по выставленному счету

С помощью API ЮKassa можно полностью или частично возвращать успешные платежи. Порядок действий при возврате платежа по выставленному счету не отличается от оформления возврата по обычному платежу.

[Подробнее об особенностях и создании возвратов, а также о неуспешных возвратах](https://yookassa.ru/developers/payment-acceptance/after-the-payment/refunds)

Для возврата вам потребуется идентификатор платежа — получите его в уведомлении по платежу от ЮKassa или в ответе на запрос информации по счету.

[Подробнее о получении идентификатора платежа](https://yookassa.ru/developers/payment-acceptance/scenario-extensions/invoices/payments#how-to-get-payment-id)
